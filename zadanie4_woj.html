1)kiedy powstał JavaScript (podaj datę).

JavaScript powstał w 1995 roku (w grudniu 1995 roku został zaimplementowany w ówczesnej wersji przeglądarki Netscape Navigator).

2)dlaczego jest to język skryptowy

Jest językiem skryptowym, czyli interpretowanym – nie trzeba go kompilować do kodu maszynowego, żeby zobaczyć efekty jego działania. Wystarczy przeglądarka internetowa, która go obsługuje.

3)gdzie jest wykonywany JS (klient lub serwer)

Po stronie klienta – w przeglądarce internetowej użytkownika (dzięki temu odciąża serwer). Przy użyciu Node.js można go też uruchamiać na serwerze.

4)dlaczego jest JS to bezpieczne narzędzie

Ze względów bezpieczeństwa JavaScript ma znacznie ograniczone uprawnienia dostępu do zasobów komputera, na którym jest przeglądana strona.

5)czy jest to język obiektowy , jeśli tak to dlaczego.

Tak, jest to język programowania obiektowego, ponieważ wykorzystuje definicje obiektów, metod i zdarzeń, które opisują właściwości obiektów. Obiekty mają określoną strukturę opisaną przez DOM (Document Object Model). Można korzystać z gotowych obiektów i metod oraz tworzyć własne i modyfikować istniejące.

6)wymień zalety JS:

Zaleta1 – prostota: język jest stosunkowo łatwy do opanowania, można zacząć go używać już po kilku minutach nauki.

Zaleta2 – ogromna popularność: w Internecie jest mnóstwo gotowych, praktycznych przykładów i stron wykorzystujących JavaScript.

Zaleta3 – uniwersalność i odciążenie serwera: ogranicza ilość zbędnych danych przesyłanych między serwerem a przeglądarką, a aplikacje mogą działać bez przeładowania strony.

7)Framework to:

Rodzaj programu (zestaw gotowych narzędzi i bibliotek) ułatwiający tworzenie innych programów i aplikacji w JavaScript, np. Angular, React, Vue.

8)Do aplikacji mobilnych można użyć Framework

React Native – pozwala budować aplikacje mobilne na różne systemy operacyjne (cross-platform).

9)Aplikacje responsywne to:

Aplikacje i strony, które dopasowują swój wygląd do rozmiaru ekranu urządzenia. JavaScript pozwala pobrać bieżący rozmiar ekranu, a dzięki HTML i CSS można zmieniać rozmiar treści, ukrywać, zmniejszać, powiększać lub przesuwać elementy tak, aby dobrze wyglądały na każdym ekranie.

10)Przepisz linie kody pod nimi wytłumaczenie jak działa ten fragment kodu

‹input type="button" name="przycisk" value="Nowa Strona" onclick="WinOpen(' ')"›

Ta linia tworzy na stronie przycisk (input typu button) o nazwie „przycisk” z napisem „Nowa Strona”. Atrybut onclick oznacza zdarzenie kliknięcia – po kliknięciu przycisku wywoływana jest funkcja WinOpen(), która otwiera nowe okno przeglądarki.

11)Przepisz linie kody pod nimi wytłumaczenie jak działa ta ten fragment kodu

window.open("obraz.html","okienko","toolbar=no,directories=no,menubar=no,height=280,width=160,top=200,left=200");

Metoda window.open() otwiera nowe okno przeglądarki. Pierwszy parametr ("obraz.html") to plik wyświetlany w nowym oknie, drugi ("okienko") to nazwa okna, a trzeci to lista opcji jego wyglądu:

toolbar=no – ukrywa pasek narzędzi (przyciski przeglądarki)

directories=no, – ukrywa przyciski katalogów (pasek łączy)

menubar=no, – ukrywa pasek menu

height=280, – wysokość okna to 280 pikseli

width=160, – szerokość okna to 160 pikseli

top=200, – odległość okna od górnej krawędzi ekranu to 200 pikseli

left=200 – odległość okna od lewej krawędzi ekranu to 200 pikseli

12)Opisz następującą instrukcję window.close()

Instrukcja window.close() zamyka bieżące okno przeglądarki (to, w którym została wywołana). Zwykle jest podpięta pod przycisk „zamknij okno”.

Jak wyświetlić instrukcję, która ma się tylko wyświetlić, a nie wykonać?

Pierwsza możliwość: znak < zapisujemy jako &lsaquo; (‹), a znak > jako &rsaquo; (›) – przeglądarka wyświetla je jako zwykłe znaki i nie traktuje jako początku znacznika HTML.

Druga możliwość: kod umieszczamy w ramce, wewnątrz znacznika <xmp>...</xmp> (lub <pre>), którego zawartość przeglądarka wyświetla dosłownie, bez interpretowania znaczników:

<!DOCTYPE html> <html lang="pl"> <head> <meta http-equiv="Content-Type" content="text/html; charset=utf-8"> <meta http-equiv="Content-Script-Type" content="text/javascript"> <title>Moja strona WWW</title> <script type="text/javascript"> function onclickHandler() { alert('Akapit został kliknięty!'); } </script> </head> <body> <p onclick="onclickHandler();">Kliknij ten akapit, a pojawi się okno dialogowe.</p> </body> </html>
